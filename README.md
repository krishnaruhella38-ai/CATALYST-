# Catalyst

### Plan Better. Track Progress. Achieve More.

Catalyst is a student productivity and life management web application designed to help students organize their academic activities, manage daily tasks, track goals, and stay productive through a simple dashboard.

## Features

- **User Authentication:** Secure registration and login system.
- **Dashboard:** Overview of important academic activities.
- **Task Management:** Add, update, complete, and delete tasks.
- **Goal Tracking:** Create and monitor personal goals.
- **Assignment Management:** Organize and track academic assignments.
- **Feedback System:** Submit feedback and view feedback shared by other users.

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Catalyst.git
```

2. Navigate to the project directory:

```bash
cd Catalyst
```

3. Install the required dependencies:

```bash
pip install -r "phase 2/requirements.txt"
```

4. Run the Flask application:

```bash
cd "phase 2"
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000/
```
